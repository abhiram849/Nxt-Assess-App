# Nxt Assess App

A web-based assessment application built with React. The application provides a user-friendly interface for taking assessments, answering questions, and viewing evaluation results.

## 🚀 Features

* User authentication and login
* Assessment interface
* Multiple questions and answer options
* Evaluation and result tracking
* Protected routes
* Context API for state management
* Responsive user interface
* API integration for authentication and assessment data

## 🛠️ Technologies Used

* **React.js**
* **JavaScript (ES6+)**
* **React Router**
* **Context API**
* **CSS3**
* **Vite**
* **REST APIs**
* **Git & GitHub**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abhiram849/Nxt-Assess-App.git
```

Navigate to the project directory:

```bash
cd Nxt-Assess-App
```

Install dependencies:

```bash
npm install
```

## ▶️ Run the Application

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🔐 Environment Variables

If the project uses environment variables, create a `.env` file in the project root and add the required configuration.

Example:

```env
VITE_API_URL=your_api_url
```

Do not commit sensitive credentials, API keys, passwords, or `.env` files to GitHub.
